# BookCycle — 二手書交換平台規格書

## 一、專案名稱

**BookCycle — Secondhand Book Exchange Platform**

**Slogan:** Give a book you have, get a book you want.

## 二、專案背景與動機

許多人家中都有已經閱讀完畢、卻不再使用的實體書籍。這些書籍仍然具有閱讀價值，但可能因為二手轉售價格不高，或出售流程較為繁瑣，而長期閒置。

因此，我希望設計一個以「書籍交換」為核心的網站，讓使用者不需要透過金錢交易，就能利用自己擁有的書籍交換其他感興趣的書籍。

BookCycle 希望透過簡單的書籍探索、收藏及交換流程，讓閒置書籍重新流通，減少資源浪費，同時提供讀者另一種取得書籍的方式。

## 三、專案目標

本專案希望開發一個可以實際操作的二手書交換網站，主要目標如下：

1. 提供使用者瀏覽及搜尋其他人上架書籍的功能。
2. 允許使用者新增、編輯和刪除自己的二手書籍。
3. 提供願望清單功能，讓使用者收藏感興趣的書籍。
4. 建立完整的雙向交換邀請機制，包含送出、接受、拒絕及取消邀請。
5. 讓雙方在同意交換後取得聯絡方式，自行協調面交或郵寄。
6. 透過雙帳號模擬，測試不同使用者之間的交換流程。
7. 使用瀏覽器本機儲存功能保存資料，並提供示範資料還原機制。

## 四、目標使用者

本網站主要針對喜歡閱讀實體書籍、擁有閒置書籍，並願意透過交換取得其他書籍的使用者，例如學生、一般讀者，以及希望減少購書支出或支持資源循環利用的人。

## 五、網站功能規格

### 5.1 使用者登入與登出

網站提供兩個示範使用者帳號：Mia 和 Kevin。

使用者可以在登入畫面選擇其中一個帳號，進入網站後操作各自的書籍、收藏及交換邀請，也可以登出並切換至另一個帳號。

由於本次作品為前端展示版本，因此不需要密碼，也不包含真正的會員身分驗證功能。兩個帳號共用同一瀏覽器的本機資料，以模擬不同使用者之間的互動。

### 5.2 Explore — 書籍探索

Explore 為網站主要首頁，顯示其他使用者目前可以交換的書籍。

功能包含：

- 以卡片形式顯示書籍封面、書名、作者、書況及擁有者。
- 支援依書名或作者進行關鍵字搜尋。
- 支援依文學小說、自我成長、心理學、設計、歷史人文等分類篩選。
- 點擊書籍卡片可查看詳細資訊，包含描述及書況。
- 可以將書籍加入願望清單，或直接提出交換邀請。
- 只顯示其他使用者擁有且目前可交換的書籍，不顯示自己的書籍或已被保留的書籍。

### 5.3 My Books — 我的書架

使用者可以在 My Books 頁面管理自己願意交換的書籍。

功能包含：

- 新增書籍，填寫書名、作者、分類、書況、ISBN 及書籍描述。
- 設定書籍封面網址，或上傳書本照片。
- 編輯已上架書籍的相關資訊。
- 刪除不再提供交換的書籍。
- 若書籍涉及進行中的交換或待處理邀請，限制部分編輯及刪除操作，避免影響交換紀錄。

新增的書籍會顯示在另一個帳號的 Explore 頁面。

### 5.4 Wishlist — 願望清單

使用者可以在 Explore 頁面點擊書籍卡片上的愛心按鈕，將感興趣的書籍加入 Wishlist。

再次點擊愛心可以取消收藏，所有收藏書籍會集中顯示於 Wishlist 頁面，方便使用者之後查看或提出交換。

不同帳號擁有各自的願望清單。

### 5.5 Sent — 我提出的交換邀請

使用者可以在書籍詳細資訊中點擊「提出交換」，選擇自己願意提供的一本書，向對方送出交換邀請。

送出邀請時可以填寫留言，說明交換意願。

Sent 頁面會顯示目前帳號主動發出的所有交換邀請，包括：

- 交換對象及提出時間。
- 我提供的書籍。
- 我想交換到的書籍。
- 交換留言及交付安排。
- 目前交換狀態。
- 在對方尚未回覆時取消邀請。

送出後系統會將邀請狀態設為 Pending，等待對方回覆。

### 5.6 Received — 收到的交換邀請

Received 頁面顯示其他使用者向目前帳號提出的交換邀請。

每筆邀請清楚區分：

- 對方提供的書籍。
- 對方想交換到的書籍。
- 交換留言及提出時間。
- 目前處理狀態。

使用者可以選擇接受或拒絕邀請。為了降低誤操作的可能性，在執行接受或拒絕之前，系統會先顯示二次確認視窗。

此外，導覽列的 Received 項目設有數字提醒，顯示目前尚未回覆的交換邀請數量。當使用者接受或拒絕邀請後，提醒數字會同步更新。

### 5.7 交換狀態管理

系統提供以下五種交換狀態：

| 狀態 | 說明 |
|---|---|
| Pending | 邀請已送出，等待對方回覆 |
| Accepted | 對方接受邀請，等待安排交付 |
| Rejected | 對方拒絕交換 |
| Cancelled | 發起者取消尚未處理的邀請 |
| Completed | 完成書籍交換 |

當邀請被接受後，雙方用於交換的書籍會暫時保留，不再提供其他交換。若有其他待處理邀請涉及相同書籍，系統會將其更新為拒絕狀態，以避免重複交換。

完成交換後，系統會更新交換紀錄及書籍狀態。

### 5.8 聯絡方式與交付安排

當雙方同意交換後，系統才會顯示對方預先設定的聯絡方式，包含 Email、LINE ID 或電話。

使用者可以自行聯絡對方，並選擇以下交付方式：

- **面交：** 約定捷運站等公共場所進行交換。
- **郵寄：** 自行協調便利商店店到店或其他寄送方式。

使用者可以在網站中填寫交付安排，雙方皆可查看。

本網站不提供站內私訊、金流或物流系統串接，而是以交換成功後提供聯絡方式的方式，簡化整體流程。

### 5.9 Profile — 個人頁面

個人頁面提供使用者基本資料及活動統計，包括：

- 使用者名稱、所在地及個人簡介。
- 已上架書籍數量。
- 願望清單收藏數量。
- 已完成的交換次數。
- 聯絡方式設定與修改。
- 登出及切換帳號。
- 示範資料重設功能。

### 5.10 示範資料與重設功能

網站預先建立 Mia 和 Kevin 兩個測試帳號及八本示範書籍，並在初始書籍資料中設定書名、作者、ISBN、書況及部分書籍的真實封面網址。

為方便反覆測試，系統提供 Reset Demo Data 功能。

此功能會還原至首次使用指定版本時保存在瀏覽器中的示範資料狀態，包含書籍、收藏、交換紀錄及聯絡資訊，並保留固定示範書籍的指定封面網址。

使用者可以反覆操作雙人交換流程，並在完成測試後還原資料。

## 六、使用者操作流程

1. 使用 Mia 帳號登入網站。
2. 在 Explore 瀏覽 Kevin 上架的書籍。
3. 選擇感興趣的書籍，並選擇自己願意提供的書籍。
4. 送出交換邀請，在 Sent 頁面查看等待回覆的紀錄。
5. 登出並切換至 Kevin 帳號。
6. 在 Received 頁面查看新收到的交換邀請通知。
7. Kevin 查看交換內容，並決定接受或拒絕。
8. 若接受交換，雙方即可查看彼此留下的聯絡方式。
9. 雙方選擇面交或郵寄，填寫交付安排。
10. 交換完成後，將狀態更新為 Completed。

## 七、介面設計

網站採用簡約、溫暖的線上書店風格，以森林綠、奶油白及淺米色作為主要配色。

上方導覽列使用英文，包含 Explore、My Books、Wishlist、Received、Sent 和 Profile。

書籍探索頁面使用卡片式排版，呈現書籍封面及基本資訊。

交換邀請頁面則使用分區與不同底色，清楚區分交換對象、提供的書籍、希望取得的書籍、留言及交付資訊，減少使用者閱讀時的混淆。

網站也提供響應式版面，讓桌面與手機螢幕可以使用不同的排列方式。

## 八、技術規格

| 技術 | 用途 |
|---|---|
| HTML5 | 建立網頁結構與各功能頁面 |
| CSS3 | 網站配色、卡片、彈出視窗及響應式版面 |
| JavaScript | 搜尋、收藏、書籍管理、帳號切換及交換流程 |
| LocalStorage | 儲存書籍、聯絡方式、收藏、交換紀錄及示範資料 |
| Open Library / Google Books | 書籍封面查詢與備援來源 |
| GitHub Pages | 靜態網頁公開部署平台 |

本次網站整合於單一 `index.html` 檔案，CSS 和 JavaScript 皆寫在 HTML 內，不需要安裝其他軟體即可在瀏覽器中開啟操作。

## 九、系統限制

本次作品屬於前端互動原型，主要目的是呈現二手書交換網站的基本操作及使用者流程。

目前尚未建置後端伺服器與真正的會員系統。Mia 與 Kevin 為示範帳號，兩個帳號的資料保存在同一個瀏覽器的 LocalStorage，因此無法讓不同裝置的使用者即時同步交換資訊。

此外，本網站不包含站內私訊、付款及物流串接功能，實際交付需由使用者透過外部聯絡方式自行安排。部分書籍封面亦依賴外部圖片來源，可能因來源服務限制而無法載入。

## 十、AI 協作與開發過程

本專案使用 Vibe Coding 的方式開發，主要透過與 AI 反覆討論需求、產生程式碼、調整功能並修改網頁。

最初的想法是建立一個簡單的二手書交換網站，包含書籍探索、我的書架、願望清單及提出交換功能。

在實作過程中，我發現單純送出交換請求，無法完整模擬兩名使用者之間的互動，因此進一步加入雙帳號切換、收到與送出邀請的獨立頁面，以及接受、拒絕和取消交換的操作。

為了讓交換流程更完整，後續也加入交換狀態管理、聯絡方式揭露、面交與郵寄安排等功能。

在使用者介面方面，透過反覆調整交換邀請卡片的文字與顏色，讓使用者能清楚分辨雙方提供的書籍及目前狀態，並新增未處理交換邀請的數字提醒。

最後，也針對書籍封面來源、示範資料保存及重設流程進行修改，讓網站更適合課堂展示及重複操作測試。
